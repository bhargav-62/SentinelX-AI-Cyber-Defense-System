# 🛡️ SentinelX AI – Cyber Defense System

SentinelX AI is an AI-powered cybersecurity monitoring and IP threat intelligence platform developed using Python, Streamlit, Plotly, and Pandas.

The platform analyzes public IP addresses, visualizes approximate geolocation data, simulates network threat monitoring, and provides intelligent cybersecurity analytics through an interactive dashboard.

---

# 🚀 Features

- 🌍 Public IP Address Intelligence
- 📍 Approximate IP Geolocation Mapping
- 🔐 Cybersecurity Threat Monitoring
- 📊 Interactive Security Dashboard
- 📡 Simulated Network Activity Analysis
- 🚨 Threat Detection and Alerts
- 📈 Real-time Analytics Visualization
- 🎨 Modern Cybersecurity UI
- ⚡ Interactive Dashboard Experience

---

# 🛠️ Technologies Used

- Python

# 📸 Dashboard Modules

## 🔐 Security Overview
Displays:
- Threat level
- System activity
- Request analytics

## 🌍 IP Intelligence
Analyzes:
- Public IP address
- Country and city
- Organization details
- Timezone information

## 🗺️ Approximate IP Location

## 🚨 Threat Detection
Identifies:
